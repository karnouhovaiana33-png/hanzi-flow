# Кулинарная битва · 汉字厨房

Мини-игра для практики китайских иероглифов. Игрок выбирает ступень сложности и направление мастер-класса, читает заказ посетителя и отправляет нужные ингредиенты в кухонную посуду.

## Ступени сложности

- **Ученик шефа** — иероглифы, пиньинь и перевод.
- **Знаток рецептов** — иероглифы и пиньинь.
- **Мастер вока** — только иероглифы.

## Мастер-классы

- Салаты: овощи и фрукты.
- Горячие блюда: мясо, лапша, рис, тофу и приправы.
- Десерты: продукты для выпечки, кремы и фрукты.
- Напитки: смузи, лимонады, чайные и кофейные напитки.
- Испытание шифу: смешанный набор слов и китайские блюда.

## Как запустить

Откройте `index.html` в браузере или запустите любой локальный статический сервер в этой папке.

## Публикация на GitHub Pages

Загрузите содержимое папки `culinary-battle` в отдельный репозиторий, затем откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.

Все игровые данные находятся в `script.js`, поэтому новые блюда и ингредиенты можно добавлять без сервера и базы данных.
