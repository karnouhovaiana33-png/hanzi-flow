# Hanzi Flow

Интерактивный пазл для тренировки китайских иероглифов.

## Механика

- уровень «Ученик»: 4 фрагмента, следующий уровень открывается после 3 иероглифов;
- уровень «Знаток»: 8 фрагментов и цель из 5 иероглифов;
- уровень «Мастер»: 16 фрагментов и цель из 7 иероглифов;
- уровень «Шифу»: иероглиф нужно запомнить за 3 секунды и собрать за минуту по почти исчезнувшим чернилам.

Прогресс открытия уровней сохраняется в браузере. Набор иероглифов можно менять во время игры.
